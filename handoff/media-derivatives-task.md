# Task: build posters + autoplay previews for every live portfolio clip

Repo: hwangyksiriai/SIRIAI_portfolio-2 (Next.js, Vercel; production deploys from `master`). Work on `master` (`git checkout master && git pull`), it should be at `92503dd` or later.

## Why
The live portfolio (portfolio.siriai.co.kr) autoplays every visible video card. To keep Vercel Blob transfer low (~97GB last cycle), `app/PortfolioView.jsx` (`Clip` / `derivedFor`) autoplays a small preview from `public/media-derived/` instead of the Blob original when `lib/media-derived.json` has an entry for the clip. Entries are keyed by the clip URL's **decoded pathname** (e.g. `/999ec6...d6a.mp4`) → `{ "poster": "/media-derived/<id>.jpg", "preview": "/media-derived/<id>.mp4" }`.
The live store renamed every file to a content-hash name, so **none of the 357 live clips match today**: every card streams its full original from Blob. This task fixes that.

## Do
1. For each URL in the list below (all on `nszercb65dwwbzyo.public.blob.vercel-storage.com`, public, no auth; this session's environment allows that host): download it to a temp dir **outside the repo**, then with ffmpeg (installed at /usr/bin/ffmpeg) make, using the same settings as the existing derivatives (see `scripts/prepare-media.mjs` on branch `perf/visible-video-previews`):
   - poster: `-frames:v 1 -vf thumbnail=60,scale=480:480:force_original_aspect_ratio=decrease -q:v 3` → `public/media-derived/<id>.jpg`
   - preview: `-t 6 -an -vf fps=15,scale=480:480:force_original_aspect_ratio=decrease:force_divisible_by=2 -c:v libx264 -preset medium -crf 28 -pix_fmt yuv420p -movflags +faststart` → `public/media-derived/<id>.mp4`
   - `<id>` = first 16 hex chars of sha256(`"preview-v1:"` + file bytes), same as the existing ones.
   - Add/overwrite the entry in `lib/media-derived.json` keyed by the decoded URL pathname. Keep existing entries, keep keys sorted, 2-space JSON + trailing newline.
   - **Delete each downloaded original right after processing** (disk is limited). Never commit originals. Process sequentially; retry a failed download once; collect failures and continue.
   - Some originals are HEVC; the previews are H.264, which is fine (and fixes playback in browsers without HEVC).
2. Do not change `app/`, the Blob store, the site config, or the admin. Data + derived files only.
3. Verify: every URL has an entry whose two files exist; `npm ci` if needed, `npm run build` passes. Spot-check a few posters by viewing them (portrait vs landscape look right).
